# AI Makeup Rules & Shade Matching Schema (`docs/MAKEUP_RULES.md`)

## Overview
GlowAI AI Makeup Engine maps skin tone measurements (Level 1-6, ITA°, Undertone) to foundation depth buckets, concealer shades, and flattering lip/blush color families.

## Depth & Undertone Classification
- **Depth Buckets:**
  - Level 1: `Fair`
  - Level 2: `Light`
  - Level 3: `Light-Medium`
  - Level 4: `Medium`
  - Level 5: `Tan`
  - Level 6: `Deep`
- **Undertones:** `Warm`, `Neutral`, `Cool`

## Occasion Guides
Supported occasions: `Casual`, `Office`, `Party`, `Wedding`, `College`, `Festival`.
Each occasion dictates:
1. Desired finish (Dewy, Satin, Matte, HD Luminous)
2. Coverage level
3. Eye look description
4. Longevity & setting tips
5. Step-by-step ordered application guide (Prep → Primer → Foundation → Concealer → Set → Blush → Eyes → Lips → Setting Spray).
